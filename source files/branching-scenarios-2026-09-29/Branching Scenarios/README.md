# Branching Scenarios

Ten populated scenarios for Contemporary Leadership in Sport Organizations, 3rd Edition. Start with PACKAGE-NOTES.md for handoff details and pending checks.

- branching-scenarios.html: scenario selection and completion reset.
- scenario-1.html through scenario-10.html: scenario pages.
- scenario-engine.js: shared keyboard, feedback, progression, and summary behavior.
- scenario-data/: current scenario and reflection content; decision counts vary.
- styles.css: integration styling and accessibility fixes.
- index.html: local preview shell, not the destination site's main page.

Preserve the directory structure. Home links in integrated scenario pages target ../../index.html. This package is for website integration; its legacy manifest files have not been validated for LMS import.
